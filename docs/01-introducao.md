# 01 - Introdução à Lógica de Programação

## O que é lógica de programação?

Lógica de programação é a forma de organizar pensamentos e instruções para resolver problemas de maneira clara e estruturada. Antes de aprender uma linguagem de programação, é importante compreender como transformar um problema em uma sequência de passos que um computador possa executar.

## Por que aprender lógica de programação?

A lógica de programação é uma base importante para o desenvolvimento de software. Ela ajuda a desenvolver a capacidade de analisar problemas, criar soluções e organizar algoritmos.

Neste guia, utilizaremos a linguagem C para colocar esses conceitos em prática.

## O que você vai aprender?

Ao longo deste guia, você aprenderá:

- Conceitos básicos de lógica de programação;
- Variáveis e tipos de dados;
- Operadores;
- Entrada e saída de dados;
- Estruturas condicionais;
- Estruturas de repetição;
- Vetores;
- Exercícios práticos.

## Como utilizar este módulo

Leia os conceitos apresentados e tente compreender cada exemplo antes de avançar. Sempre que possível, pratique escrevendo seus próprios programas em C.

Ao terminar esta introdução, avance para o módulo de conceitos fundamentais.
