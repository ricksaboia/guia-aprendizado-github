# 04 - Referências

## Objetivo

As referências apresentadas nesta seção servem como apoio para aprofundar os conhecimentos sobre a linguagem C e lógica de programação.

## Documentação da linguagem C

A documentação e os materiais de referência da linguagem C podem ser utilizados para consultar funções, tipos de dados, operadores e outros recursos da linguagem.

- cppreference — C Language
- GNU C Library Documentation

## Materiais de estudo

Para continuar estudando lógica de programação e linguagem C, também é recomendado consultar livros, cursos e materiais didáticos voltados para iniciantes.

Alguns temas importantes para continuar estudando são:

- Algoritmos;
- Estruturas de dados;
- Ponteiros;
- Funções;
- Matrizes;
- Strings;
- Alocação dinâmica de memória.

## Recomendações

Ao utilizar materiais externos, procure fontes confiáveis e dê preferência à documentação oficial ou a materiais educacionais reconhecidos.

Também é importante praticar os conceitos aprendidos por meio da criação de pequenos programas e resolução de problemas.

## Conclusão do guia

Ao finalizar este guia, o estudante terá uma base inicial de lógica de programação utilizando C e poderá continuar seus estudos em tópicos mais avançados da programação.
