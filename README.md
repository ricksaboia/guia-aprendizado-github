# Fundamentos de Lógica de Programação com C

## Objetivo

Ensinar os fundamentos da lógica de programação utilizando a linguagem C, apresentando conceitos básicos, exemplos práticos e exercícios para que iniciantes desenvolvam seus primeiros programas.

## Público-alvo

Estudantes iniciantes em programação, especialmente aqueles que estão tendo seu primeiro contato com lógica de programação e com a linguagem C.

## Pré-requisitos

Não é necessário conhecimento prévio em programação. É recomendado ter um computador com acesso à internet e um ambiente para escrever e executar códigos em C.

Recomenda-se seguir o guia na ordem apresentada, começando pela introdução, passando pelos conceitos fundamentais, realizando os exercícios e, por fim, consultando as referências para aprofundar os conhecimentos.
