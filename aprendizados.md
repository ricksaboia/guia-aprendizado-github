# Aprendizados

## Sobre o desenvolvimento do projeto

Durante o desenvolvimento deste guia, pude praticar a organização de um projeto utilizando Markdown, Git e GitHub.

A criação dos módulos em arquivos separados ajudou a organizar o conteúdo e facilitou a navegação pelo material.

## Sobre Git e GitHub

Durante o projeto, pratiquei a criação e utilização de branches, a realização de commits e o envio das alterações para um repositório remoto.

Também utilizei Pull Request para revisar alterações antes de integrá-las à branch principal.

## Sobre commits

Aprendi que commits devem representar alterações claras e específicas. Utilizar mensagens descritivas facilita a compreensão do histórico do projeto e ajuda na manutenção do repositório.

## Sobre colaboração e revisão

O Pull Request permite visualizar as alterações realizadas em uma branch antes que elas sejam integradas à `main`.

Esse processo facilita a revisão e ajuda a identificar possíveis problemas antes da integração.

## Reflexão final

O desenvolvimento do projeto mostrou que Git e GitHub não servem apenas para armazenar código. Eles também ajudam a organizar o processo de desenvolvimento, acompanhar mudanças e documentar as etapas realizadas.

A utilização de branches, commits e Pull Requests tornou o desenvolvimento mais organizado e permitiu acompanhar a evolução do projeto de forma estruturada.
