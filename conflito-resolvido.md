# Conflito Resolvido

## Situação

Foi criado um conflito controlado no arquivo `README.md`.

A branch `main` alterou o título para:

> Guia de Introdução à Lógica de Programação com C

Enquanto a branch `feature/conflito` alterou a mesma linha para:

> Fundamentos de Lógica de Programação com C

Como as duas branches modificaram a mesma linha de maneiras diferentes, o GitHub não conseguiu realizar o merge automaticamente.

## Resolução

O conflito foi resolvido manualmente durante o Pull Request.

As duas versões foram analisadas e foi criada uma terceira versão coerente:

> Guia de Fundamentos de Lógica de Programação com C

Os marcadores de conflito foram removidos e o resultado final foi confirmado pelo GitHub.

## Decisão

A versão final combina as ideias das duas alterações e mantém o título alinhado ao objetivo do guia.

## Resultado

O conflito foi resolvido, a alteração foi registrada no histórico da branch e o Pull Request ficou pronto para integração na `main`.
